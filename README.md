# AI 表格助手（Obsidian 插件）

一个由 AI 帮忙填表的 Obsidian 表格工作台。收到订单、送货单、价格表、截图时拖进来，它会推荐该填哪张表，再由 AI 识别内容填进去，最后按原 Excel 的格式导出。

## 功能

- **导入表格**：支持 csv / tsv / xlsx / xlsm / md，可以拖入文件或整个文件夹（单个文件上限 200MB）。多工作表的 Excel 会按工作簿分组，底部像 Excel 一样用标签切换工作表。
- **AI 填表**：在对话框里发图片、PDF 或表格，AI 识别后新增行、修改单元格、增删列、排序等。修改前可以先预览（黄色是修改，绿色是新增），确认后再应用，也可以撤销。
- **自动找表**：收到单据直接拖到「收到单据」入口，按列名比对和 AI 判断，推荐该填的表。
- **按原格式导出**：改完后整本导出 Excel，保留原来的颜色、字体、边框、公式、合并单元格和图片。新增的行会沿用上一行的格式和公式。
- **附件区**：图片、PDF 等任何文件都可以存档，带缩略图预览，图片可以一键复制；要用时点「送去提取」交给 AI。
- **操作记录**：首页按时间列出 AI 修改、手动修改、导入导出、删除等操作，可以查看每个格子原来是什么、改成了什么。
- **AI 服务**：支持 Claude（Anthropic）、DeepSeek，以及兼容 OpenAI 接口的服务（通义千问、Kimi、豆包等）。

## 安装

1. 在你的 Obsidian 库里新建文件夹 `.obsidian/plugins/ai-table-assistant/`。
2. 把本仓库的 `main.js`、`styles.css`、`manifest.json` 放进去。
3. 重启 Obsidian，在「设置 → 第三方插件」里启用「AI 表格助手」。
4. 在插件设置里选择 AI 服务，填写 API Key。

API Key 只保存在你本地库的 `data.json` 里，不会上传到这个仓库。

## 数据保存位置

- 表格默认保存在库里的 `AI表格助手/` 文件夹（可以在设置里改）。
- 导出的文件在 `AI表格助手/导出/`。
- 附件在 `AI表格助手/附件区/年-月/`。
- 原 Excel 的副本、格式对应关系和操作记录在 `AI表格助手/.ata/`。
