# 表格工作台（Obsidian 插件）

Obsidian 负责**存放、展示和记录**，改表格、算数交给外部 AI（能读写电脑文件的 AI 工具，例如 Claude 桌面版、Claude Code、Codex）。

## 工作方式

1. **导入**：Excel 导入时自动转换成 AI 能快速读写的底层数据——每个工作表一个 CSV，放在 `表格工作台/数据/`；同时在 `表格工作台/表格/` 生成一份原表 Excel。
2. **AI 修改**：AI 按 `操作守则.md` 直接改 `数据/` 里的 CSV（加几行、改几格、算金额），不用打开又大又慢的原生 Excel。新行可以插在表格中间，删行也会整行删除——生成原表时像 Excel 一样整行插入 / 删除，下面的行、公式、合并单元格、图片、批注跟着移动，合计公式范围自动扩展。
3. **自动生成原表**：数据一改，插件在几秒内按原 Excel 的格式（颜色、字体、边框、公式、合并单元格、图片）重新生成 `表格/` 里的 Excel，覆盖上一版。Excel 正打开着时会自动等待重试。
4. **记录**：每次修改哪些格子从什么改成什么、新增了哪些行、原表是否已更新，都记在首页日志和 `操作日志.md` 里；AI 写在 `自动处理/记录/` 的处理说明也会收进日志。改错了可以一键撤销。

## 页面

- **日志**：所有操作按时间排列，可以查看明细、撤销最近一次修改；顶部可以打开「新手教程」「操作守则」「数据目录」，点「复制 AI 开场白」直接粘贴给外部 AI。
- **文件管理**：每个表格文件一行，显示行数、数据更新时间、原表是否最新；勾选后批量复制原表地址、复制数据地址、复制原表文件、立即更新原表、删除。
- **附件区**：单据、截图、PDF 等任何文件；可以新建文件夹分类、移动文件；多选后批量复制文件（Windows 可直接粘贴到微信、资源管理器）或复制路径。按日期分组显示。

## 附件 AI 扫描

在设置里选服务商（DeepSeek、通义千问、豆包、智谱、OpenAI、Claude 或任意 OpenAI 兼容接口），填 API Key。之后存进附件区的图片 / PDF 会自动识别单据上的日期，放进 `年-月`（或 `年-月/月-日`）文件夹，并按「日期_类型_对方_单号」改名；旧附件点「AI 按时间整理」一次处理。API Key 只保存在本机。

## 给 AI 的文件

插件在 `表格工作台/` 里自动生成并更新：

- `新手教程.md`：给使用者看的上手教程，包括怎么配合外部 AI 使用、可以照抄的指令。
- `操作守则.md`：文件夹结构、改表规则、导入导出方法、记录要求。让 AI 干活前先读它。
- `数据目录.md`：所有表格的位置、列名、行数和样例。
- `操作日志.md`：所有操作记录，最新的在最上面。

## 自动处理

- 把 Excel 放进 `自动处理/导入/` 自动导入；放进 `自动处理/导入/替换/` 替换同名的旧表。
- 在 `自动处理/导出/` 放一个写着「表格: 名称」「输出: 路径」的 txt，可以另存一份原表到指定位置。
- 在 `自动处理/记录/` 放 txt 处理说明，会收进日志。
- 也可以用 `obsidian://table-workbench?action=import|export|open` 链接调用。

## 安装

**用 BRAT**：添加仓库 `Unclesam-13/excelai`。
**手动**：把 `main.js`、`styles.css`、`manifest.json` 放进库里的 `.obsidian/plugins/ai-table-assistant/`，重启后启用「表格工作台」。

换电脑时请把整个库连同隐藏的 `表格工作台/.ata/` 文件夹一起复制（里面是原 Excel 副本和格式信息）。
