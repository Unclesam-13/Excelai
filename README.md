# 表格工作台（Obsidian 插件）

在 Obsidian 里集中存放、查看和整理表格：Excel 导入后按原样显示，可以直接修改，最后按原格式导出；收到的单据、截图也有地方归档。

## 功能

- **按原 Excel 的样子显示**：标题行、合并单元格、列宽行高、冻结窗格、底色、字体、边框、对齐、数字和日期格式都和 Excel 一样，左边是行号、上面是列标，底部像 Excel 一样切换工作表。点格子查看内容，双击就切到编辑。
- **编辑数据**：简洁的表格视图，直接改格子、加行加列、删行删列、撤销。两种视图看的是同一份数据。
- **按原格式导出**：从 Excel 导入的表导出时保留原文件的颜色、字体、边框、公式、合并单元格和图片，多个工作表一起导出成一个文件；新增的行沿用上一行的格式和公式。
- **导入**：支持 xlsx / xlsm / csv / tsv / md，可以拖入文件或整个文件夹（单个文件上限 200MB），多工作表的 Excel 按工作簿分组。
- **外部修改提示**：表格文件被其它程序改过（包括工作台关着的时候），会标出新增的行和改过的格子，可以确认或一键撤销。
- **操作记录**：首页按时间列出导入、修改、导出、删除等，可以查看每个格子原来是什么、改成了什么。
- **附件区**：单据、截图、PDF 等任何文件按月份归档，带缩略图预览，图片可以一键复制。
- **自动处理**：Obsidian 开着时，把 Excel 放进 `表格工作台/自动处理/导入/` 会自动导入（放进 `导入/替换/` 则替换同名的旧表）；在 `自动处理/导出/` 放一个写着「表格: 名称」「输出: 路径」的 txt 文件就会自动按原格式导出；每次处理都会生成 `.结果.txt` 说明结果。也可以用 `obsidian://table-workbench?action=import|export|open` 链接调用。其它程序（脚本、AI 工具等）只要能读写文件就能完成「Excel → 修改 → Excel」的全过程。
- **设置自动备份**：工作簿分组、格式对应等信息另存一份在表格文件夹里，插件设置丢了也能自动恢复。

## 安装

**用 BRAT**：安装 BRAT 插件后，添加仓库 `Unclesam-13/excelai`。

**手动**：下载 `main.js`、`styles.css`、`manifest.json`，放进库里的 `.obsidian/plugins/ai-table-assistant/`，重启 Obsidian 后在「第三方插件」里启用「表格工作台」。

## 数据保存位置

- 表格：库里的 `表格工作台/`（旧版本叫 `AI表格助手/`，升级后会自动改名，内容一起搬过去）
- 导出文件：`表格工作台/导出/`
- 附件：`表格工作台/附件区/年-月/`
- 原 Excel 副本、格式信息、修改前的版本、操作记录、设置备份：`表格工作台/.ata/`（隐藏文件夹，换电脑时请一起复制）
