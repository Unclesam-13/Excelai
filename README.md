# AI 表格助手 · 表格工作台（Obsidian 插件）

Obsidian 负责**存放和展示**表格，识别单据、填表这些活交给你自己用的 AI（Claude、ChatGPT 等）。AI 直接修改库里的表格文件，插件自动对比出改了哪里、标出来，你确认或撤销，最后按原 Excel 的格式导出。

## 工作流程

1. **导入表格**：把平时要填的 Excel / CSV 导进来（支持多工作表 Excel、整个文件夹，单个文件上限 200MB）。每张表都会变成库里的一个 CSV 文件。
2. **存进单据**：订单、送货单、价格表的截图或 PDF 拖到首页「收到单据」，存进附件区，再选要填的表。
3. **复制指令给 AI**：在工作区右侧「交给外部 AI」面板写要求（或点常用要求），点「复制给 AI 的指令」。指令里写好了说明文件、表格和附件的完整路径。
4. **AI 改文件**：把指令粘贴给能读写电脑文件的 AI 工具（例如 Claude 桌面版连上表格文件夹、Claude Code、Codex 等）。网页版聊天读不到你电脑上的文件。
5. **确认 / 撤销**：AI 改完，工作台立刻刷新：绿色是新增的行，黄色是改过的格子。可以确认，也可以一键撤销回修改前。工作台关着时被改的表，下次打开也会找出来。
6. **导出 Excel**：从 Excel 导入的表按原文件格式导出：颜色、字体、边框、公式、合并单元格、图片都保留，新增的行沿用上一行的格式和公式。

## 给 AI 的说明文件

插件会在表格文件夹里自动生成并更新：

- `AI使用说明.md`：文件夹结构、CSV 格式、修改规则（不改表头、新行加在末尾、不动无关内容等）。
- `表格目录.md`：所有表格的路径、来源、列名、行数和样例。
- `CLAUDE.md`、`AGENTS.md`：指向上面两个文件，方便 Claude Code、Codex 等工具自动读取。

## 其它功能

- **附件区**：任何文件都能存档，带缩略图预览，图片可以一键复制，点「交给 AI」选表即可。
- **操作记录**：首页按时间列出外部修改、手动修改、导入导出、删除等，可以查看每个格子原来是什么、改成了什么。
- **新手引导**：第一次打开时一步步介绍；之后点顶部「引导」可以再看。

## 安装

**用 BRAT**：安装 BRAT 插件后，添加仓库 `Unclesam-13/excelai`。

**手动**：从 Releases 下载 `main.js`、`styles.css`、`manifest.json`，放进库里的 `.obsidian/plugins/ai-table-assistant/`，重启 Obsidian 后在「第三方插件」里启用。

插件本身不连接任何 AI 服务，也不需要 API Key。

## 数据保存位置

- 表格：库里的 `AI表格助手/`（可以在设置里改）
- 导出文件：`AI表格助手/导出/`
- 附件：`AI表格助手/附件区/年-月/`
- 原 Excel 副本、格式对应关系、修改前的版本和操作记录：`AI表格助手/.ata/`
